Charts Test Page

Proof-of-concept: Chart.js + PapaParse loading data from data/ files in JSON or CSV. Switch formats and seasons live — charts reload from the same file, different format.

Local development note: Fetching data/ files requires an HTTP server. Run python -m http.server 8000 (or use VS Code Live Server) and open http://localhost:8000/charts-test.html. This page works normally on GitHub Pages.
